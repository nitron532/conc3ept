# Conc3ept: Cognitive Course Content Mapping <hr>

Stack:
- React (frontend)
  - Zustand (global state management)
  - Elkjs (interactive graph / tree library)
- Flask (backend)
- PostgreSQL (metadata storage)

*see [conc3eptrag repository](https://github.com/nitron532/conc3eptrag/tree/main)

make sure to add .envs to frontend folder and root folder

npm install in the frontend dir

pip install -r requirements.txt
